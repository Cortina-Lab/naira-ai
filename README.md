# Naira AI — Soul Companion

A Hinglish-native AI companion for everyday conversations: an AI friend who listens, remembers and cares.

[**Get it on Google Play**](https://play.google.com/store/apps/details?id=com.lexcore.nira_ai)

> **Showcase repository.** This repo presents a live product we built. The application source code is private.

## Features
- Natural Hindi, Hinglish and English conversation.
- Memory: Naira remembers what you share, so conversations build over time.
- Safety layer: clear AI disclosure, 18+ use, and in-app reporting of any AI answer.
- Google Sign-In and a monthly Pro plan.

Naira is an AI, not a person, and not a substitute for professional help.

## Built with
Flutter · Dart · conversation memory · safety layer
